# Coverall landing page

Static one-page site (`index.html` + `images/`). No build step.

## Publish with GitHub Pages
1. Push these files to the root of a repository (branch `main`).
2. Repository → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
3. After a minute the page is live at `https://<user>.github.io/<repo>/`.

Notes
- The page asks search engines not to index it (`noindex`); remove that meta tag in `index.html` when going public.
- GitHub Pages on the free plan needs a public repository.
- Fonts (Inter, Instrument Sans) load from Google Fonts.
